## Skill overrides

Before following any skill, check `.ai/skills/<skill-name>/SKILL.md` in this project. When present, read it first and apply it on top of the installed skill: the override wins where it is explicit, the installed skill's safety rules always win. Pass the override text to any subagent you spawn.
